Building a CLI in Go
====================

This guide walks through a small tool. You'll need __Go 1.22__ or newer.

Step 1: Project layout
----------------------

Create the module:

```bash
mkdir hello && cd hello
go mod init example.com/hello
```

Step 2: The entry point

```go
package main  

import (
	"flag"
	"fmt"
)

func main() {
	name := flag.String("name", "World", "who to greet")
	flag.Parse()
	fmt.Printf("Hello, %s!\n", *name)
}
```

Run it with `go run . -name=Zoë`.

Tips
----

* Use `go vet ./...` before committing.
* Prefer **small** interfaces — see [Effective Go][eg].
* Inline code with backticks: `` `fmt.Println` `` and escaped \`ticks\`.
